# Production

Code templates shipped inside every Matteflux set ZIP.

`templates/code/html-css/matteflux.css` and `matteflux.js` are the product
code. The site uses the same files (`site/src/assets/mf/`); keep them in sync.

## ZIP structure

Each set download contains:

```
hero/      desktop (2560×1440) + mobile (1080×1920) — MP4 + WebM
footer/    desktop (2560×854)  + mobile (1080×1350) — MP4 + WebM
posters/   first frame of each video — JPG + WebP
code/      html-css/  framer/  webflow/
README.md
```
